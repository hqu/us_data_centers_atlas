# U.S. Data Center Atlas

Maps and analysis of operating U.S. data centers, local restrictions on them, and how the two connect.

- **Operating data centers** – FracTracker Alliance
- **Local restrictions** – The Data Center Policy Database (Bridges et al., 2026, https://doi.org/10.17613/PVSTG-4A775)
- **Backlash next door** – distance, timing and state-level regression analysis
- **How Claude built this site** – sources, methods, caveats and prompts

This GitHub Pages version embeds the interactive Datawrapper and Flourish charts.
Open `index.html` through any web server; the page loads its data from the JSON files beside it.

To publish: Settings → Pages → Deploy from a branch → `main` / root.
